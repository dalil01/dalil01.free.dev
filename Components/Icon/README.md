# Icon

A robust solution for managing and implementing SVG icons as fonts in your web applications. 

This component converts SVG icons into font files, enabling easy customization through CSS while providing seamless integration with major frontend frameworks.

## **Key Features**

- Convert SVG icons into performant font files
- Native support for React, Vue, and Svelte
- CSS-based customization (size, color, styles)
- Automated font generation pipeline
- TypeScript support for type safety

## Prerequisites

- Node.js 14 or higher (https://nodejs.org/)
- TypeScript 4.x or higher (https://www.typescriptlang.org/)

## Quick Start

### 1. Install Dependencies

```bash
npm install -D fantasticon@^2.0.0
```

[Fantasticon NPM Package](https://www.npmjs.com/package/fantasticon)

### 2. Compatibility Note

`fantasticon` does not support projects using `type: module` in the `package.json`. Make sure your project is set up accordingly.

### 3. Add Required Configuration

Add this override to your `package.json` to prevent potential dependency conflicts:

```
"overrides": {
  "fantasticon": {
    "glob": "7.2.0"
  }
}
```

After adding this, run the following command to reinstall your dependencies and apply the changes:

```bash
npm install
```

### 4. Add the Generate Script

Add a custom script to your `package.json` for generating icons:

```
"scripts": {
  "generate:icons": "npx fantasticon"
}
```

### 5. Set Up Project Structure

Copy the following files and directories to your project:

- `fantasticonrc.js` → Project root
- `/src/components/Icon` → Your components directory

The Icon component structure:

```
Icon
|
├── css
|   ├── icons.css       # CSS generated by Fantasticon
|   └── icons.css.hbs   # Handlebars template for CSS customization
|
├── fonts               # Generated fonts by Fantasticon
|   ├── icons.eot  
|   ├── icons.svg  
|   ├── icons.ttf  
|   ├── icons.woff 
|   └── icons.woff2
|
├── svg                 # Your SVG icons
|
├── Icons.ts            # Icon enum definitions generated by Fantasticon
├── Icon.ts             # TypeScript component
├── Icon.tsx            # React component
├── Icon.vue            # Vue component
└── Icon.svelte         # Svelte component
```

## Configuration & Setup

### 1. Configure Icon Directory

Update `fantasticonrc.js`:

```javascript
const iconsDir = "./src/components/Icon/"; // Line 1
```

###  2. Add SVG Icons

Place your SVG files in the `svg/` directory

### 3. Generate Font Files

```bash
npm run generate:icons
```

### 4. Import Styles

Add the generated CSS file to your main stylesheet

```
@import "[path-to-your-components]/Icon/css/icons.css";
```

## Usage Examples

### TypeScript (Vanilla)

```typescript
const closeIcon: HTMLElement = Icon.get(Icons.IconClose);
document.body.appendChild(closeIcon);
```

### Framework Components
```jsx
<Icon name={ Icons.IconClose } />
```

## Troubleshooting

- **SVG Validation**: Ensure all SVG files are properly formatted and optimized
- **Framework Cleanup**: Remove unused framework components to reduce bundle size
- **Font Generation**: If font generation fails, verify that your SVG files are valid and your `fantasticonrc.js` configuration is correct
